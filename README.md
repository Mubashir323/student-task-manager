# 📋 Student Task Manager

A beginner-friendly Python task management application designed to help students organize and track their tasks.

## 📌 About

I created this project to practice Python programming and build a practical application for managing tasks.

The program allows users to add tasks, view tasks, mark tasks as completed, delete tasks, and save their tasks so they remain available after restarting the program.

## ✨ Features

- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Save tasks automatically
- Load saved tasks when the program starts
- JSON-based data storage
- Simple command-line interface

## ▶️ How to Run

Make sure Python 3 is installed.

Open Command Prompt in the project folder and run:

```bash
py student_task_manager.py
```

```text

Choose an option: 1
Enter a task: Study Python

Task added successfully! ✅
```

## 💾 Data Storage

The application uses `tasks.json` to store tasks.

This means tasks can remain available when the program is closed and opened again.
